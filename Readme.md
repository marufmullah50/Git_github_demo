# 📝 Git & GitHub Practice Repository

This repository was created for practicing basic Git and GitHub commands.  
It contains a simple `index.html` file and a `description.txt` file as practice examples.

---

## 📂 Files
- `index.html` → A sample HTML file created to test Git workflow.  
- `description.txt` → A sample text file uploaded directly to GitHub.  

---

## 🔧 Practice Steps
1. Initialize a local repository:
   git init

2. Create and edit files (e.g., index.html).

3. Stage changes:
   git add .

4. Commit changes:
   git commit -m "Initial commit"

5. Connect local repo with GitHub (HTTPS link used here):
   git remote add origin https://github.com/your-username/project.git

6. Push files:
   git push -u origin master

---

## 🎯 Purpose
This project is for learning how to:
- Create repositories on GitHub
- Upload files directly through GitHub
- Use Git commands locally (init, add, commit, push)
- Sync local and remote repositories
